How many tabs do I have open? **47** — and every single one of them is a
shopping cart I opened meaning to buy later and never checked out.
Forty-seven carts, zero purchases: a browser that shops more than I do.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt   # 47
```
